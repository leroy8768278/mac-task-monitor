# Mac 任务台

一款本地运行的原生 macOS 工具。打开 `dist/Mac 任务台.app` 即可使用。点主窗口左上角的红色关闭按钮后，任务台会收起 Dock 运行图标，继续在顶部菜单栏监控。点击菜单栏的波形图标，选择「打开 Mac 任务台」可恢复窗口和 Dock 图标，选择「退出 Mac 任务台」可彻底退出。

- **设备状态**每 3 秒采样 CPU、内存、启动磁盘和运行时间。应用会读取当前 Mac mini M4 可用的 CPU 核心温度，并显示 macOS 报告的散热状态。
- **清理释放**可扫描当前用户的应用缓存，预览并勾选要清理的软件。清理后显示实际移除的文件数和文件占用。「释放内存」使用 macOS 的 `purge` 释放内存中的文件缓存，按系统提示授权后可查看操作前后的内存读数。应用运行所需的内存仍由 macOS 管理。
- **运行软件**每 3 秒更新已启动的桌面软件和独立菜单栏软件，显示工作状态、CPU 和驻留内存。选中一行可在列表下方查看软件的功能及说明来源。需要结束软件时，点击「强制关闭」并确认，未保存的内容可能会丢失。
- **运行进程**显示当前应用及后台进程的 CPU、驻留内存、PID、用户和状态，支持筛选、列排序和暂停刷新。选中进程可查看作用、退出影响、资源占用和基本信息。常见进程附参考资料，也可按可执行文件名在浏览器中搜索。
- **已装软件**列出本机应用程序目录中的软件，勾选「包含外接磁盘」还可扫描已挂载本地卷的应用程序目录。选中软件可查看版本、安装路径、包标识、软件介绍和应用包占用的磁盘空间。点击行末的「卸载」并确认，会将选中的应用包移到废纸篓，可以在访达中恢复。置灰按钮的原因可在软件详情中查看。
- **计划任务**查看系统和当前用户的 launchd 任务，以及当前用户的 crontab。展开任务可查看中文用途、触发条件、状态和退出结果，并保留原始命令与配置路径。常见任务显示停用影响和可用的参考资料。
- **应用守护**通过「选取应用…」选择本机要守护的 `.app`。手动开启后，守护规则通过 macOS 后台项运行。若系统要求授权，可以从应用打开登录项设置。守护在当前用户已登录且设备唤醒时工作。停止守护会暂停自动重启，保留配置以便再启动。删除规则需确认，已打开的应用可以继续运行。
- **常用工具**可通过「防止休眠与熄屏」同时保持 Mac 和显示器在空闲时唤醒。点击 macOS 菜单栏的波形图标也可切换。开关默认为关闭，退出任务台时恢复系统原有的休眠策略。
  - 「一键锁屏」锁定当前会话，保留防休眠开关的状态。
  - 「一键锁屏并熄屏」会自动关闭已开启的防休眠开关，确认会话已锁定后让显示器休眠。解锁后可按需重新开启防休眠。
- **软件设置**里的「开机启动」开关默认为关闭。开启后，每次登录当前 macOS 账户时，Mac 任务台会在顶部菜单栏后台运行。点击波形图标并选择「打开 Mac 任务台」即可显示主窗口。手动打开应用时会直接显示窗口。

应用可以识别并管理当前用户的现有 MT5 规则 `local.mt5.keepalive`。停止后可恢复，确认删除后会把该 LaunchAgent 配置移到废纸篓。

## 构建

在 macOS 13 或更新的系统上安装 Apple 命令行开发工具，然后在项目目录运行 `bash Scripts/build-app.sh`。构建脚本生成适用于本机架构的 `.app`，并使用本地临时签名验证应用包。

运行 `bash Scripts/test-cache-cleaner.sh` 可在临时目录验证缓存清理，包括扫描后新增或修改的文件以及符号链接的处理。
