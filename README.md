# Mac 任务台

一款本地运行的原生 macOS 工具。打开 `dist/Mac 任务台.app` 即可使用。

- **设备状态**每 3 秒采样 CPU、内存、启动磁盘和运行时间。应用会读取当前 Mac mini M4 可用的 CPU 核心温度，并显示 macOS 报告的散热状态。
- **计划任务**查看系统和当前用户的 launchd 任务，以及当前用户的 crontab。列表支持搜索、来源筛选、仅查看运行中任务，并可展开查看规则、命令、配置路径和进程信息。cron 显示配置中的触发计划。
- **应用守护**可选择 MT5 或其他 `.app`。手动开启后，守护规则通过 macOS 后台项运行。若系统要求授权，可以从应用打开登录项设置。守护在当前用户已登录且设备唤醒时工作。需要手动退出所选应用时，先关闭自动重启。

如果当前用户会话已加载 `local.mt5.keepalive`，应用会显示并链接到这条现有 MT5 规则，避免为 MT5 重复创建守护。

## 构建

在 macOS 13 或更新的系统上安装 Apple 命令行开发工具，然后在项目目录运行 `bash Scripts/build-app.sh`。构建脚本生成适用于本机架构的 `.app`，并使用本地临时签名验证应用包。
